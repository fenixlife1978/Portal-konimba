# **App Name**: Siren's Portal

## Core Features:

- Admin Dashboard: Centralized dashboard for administrators with menu cards for Publisher management, Lead management, Payment management, Offer management, Report generation, and Receipt handling.
- Publisher Dashboard: Dedicated dashboard for publishers with menu cards for viewing pending payments, accessing historical payments, managing receipts, tracking real-time performance, and configuring settings.
- Responsive Design: Fully responsive design that adapts seamlessly to various mobile devices and screen sizes, ensuring optimal user experience.
- Themed Menu Cards: Menu cards with distinct colors that align with the Starbucks brand, providing intuitive navigation to different modules.
- Modern Iconography: Utilize a modern icon library that offers visually rich and expressive icons. These are icons representing people with vibrant colors.

## Style Guidelines:

- Primary color: Starbucks green (#00704A) for brand recognition and a connection to nature and freshness.
- Background color: Light beige (#F2F1E9), subtly tinted toward green, to evoke a calm and inviting atmosphere while aligning with Starbucks' visual identity.
- Accent color: Deep brown (#332D29) for headings and key UI elements to give emphasis without overwhelming the user, echoing coffee bean tones.
- Body and headline font: 'PT Sans', a humanist sans-serif, balances a contemporary look with a touch of warmth and personality, providing excellent readability across various digital interfaces. It will serve all needs, headline or body text.
- Incorporate custom Starbucks-themed icons in a modern, illustrative style.
- Card-based layout for menu options to create a visually appealing and touch-friendly interface.
- Subtle animations for card transitions and loading states.
